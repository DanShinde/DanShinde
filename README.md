### 🔭 Featured project

**[TagScope](https://github.com/DanShinde/tagscope)**: log OPC UA tags from any PLC to SQLite or PostgreSQL and watch them live in a fast, modern dashboard. Trends, alarms, address space browser and CSV export, all from `pip install tagscope && tagscope demo`.
